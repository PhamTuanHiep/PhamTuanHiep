## 🚀 Featured Project

### Hospital Management System

A full-stack web application developed independently as my graduation project to manage healthcare personnel and administrative operations.

**Key Features**

* User accounts and personnel profile management
* Department, position, and employment contract management
* Employee task and work schedule management
* Recruitment news and notification management
* Salary and benefits management, including Excel file uploads for frontend salary calculations before approval and database storage

**My Role:** Independently handled the project from requirements analysis and design to frontend and backend implementation.

**Tech Stack**

* **Frontend:** ReactJS, TypeScript, Ant Design
* **Backend:** NestJS, Node.js
* **Database:** MySQL
* **Image Storage:** Firebase

**Repositories:** [Frontend](https://github.com/PhamTuanHiep/Hospital_HRM_FE) · [Backend](https://github.com/PhamTuanHiep/Hospital_HRM_BE)

*Note: This project was developed as a graduation project and is no longer actively maintained.*
